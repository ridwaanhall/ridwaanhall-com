{% comment %} The site's one notification surface. This replaced five separate copies of the same idea: the Django-messages blocks in guestbook/components/messages.html, comments/_messages.html and core/components/contact_messages.html, plus the two hand-rolled JS versions (showLoginMessage() in guestbook.html and showMessage() in contact.html). All of them built the same green/red/blue bordered strip, and three of them shipped their own dismissal handler. Rendered at body level, outside #page-content, for the same reason the confirm dialog is: that element carries a transform (translate-y-8), and a transformed ancestor becomes the containing block for its position:fixed descendants -- a toast stack inside it would be positioned against the content column instead of the viewport. Django messages are rendered here as real HTML, so flash feedback still works with JS unavailable; notify.js only adds dismissal, auto-dismiss and the client-raised toasts on top. z-[60] rather than z-50: the confirm dialog sits at z-50, and a toast raised while it is open (a failed action, say) has to be readable above it. {% endcomment %}
