{% comment %} Light/dark theme toggle. Included once per sidebar variant (desktop rail and mobile drawer), so every instance shares the `data-theme-toggle` hook rather than an id -- themeToggle.js keeps them all in sync. Which icon shows is decided by CSS from `html[data-theme]`, not by JS (see the rules in static/css/input.css). That matters: the theme is applied by a blocking script in while themeToggle.js is deferred, so a JS-driven icon would flash the wrong one on every page load. The accessible name is deliberately static ("Toggle...", not "Switch to light..."). The page is server-rendered and cached while the theme lives in localStorage, so the server cannot know which state to name; a static label is always accurate. Current state is exposed via aria-pressed, which the script sets on load. {% endcomment %}
